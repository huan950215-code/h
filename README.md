# 图片无损放大工具

一个纯前端的图片放大页面：拖拽或选择图片，调节放大倍数与平滑模式，直接在浏览器内生成放大结果并下载，无需上传到服务器或运行后端代码。

## 使用方式

1. 本地打开：直接在文件管理器中双击 `index.html`，或用任意静态服务器（如 `python -m http.server`）打开根目录。
2. 部署到线上：将仓库根目录的静态文件（`index.html`、`styles.css`、`script.js`）发布到任何支持静态站点的服务（如 GitHub Pages / Netlify）。不需要 Node.js 运行时或构建步骤。
3. 浏览器访问后上传图片，设置放大倍数，点击“开始放大”即可预览与下载结果。

## 功能
- 放大倍数 1.0x - 6.0x 可调
- 可选关闭平滑插值以获得像素风的清晰放大
- 本地处理，不会上传图片数据
- 导出结果为 PNG 文件下载
