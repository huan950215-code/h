# 图片无损放大工具

一个纯前端的图片放大页面：拖拽或选择图片，调节放大倍数与平滑模式，直接在浏览器内生成放大结果并下载，无需上传到服务器。

## 使用方式

1. 启动本地静态服务器（例如 Python）：

   ```bash
   python -m http.server 8000
   ```

2. 浏览器访问 `http://localhost:8000`，上传图片并选择放大倍数，点击“开始放大”即可预览与下载结果。

## 功能
- 放大倍数 1.0x - 6.0x 可调
- 可选关闭平滑插值以获得像素风的清晰放大
- 本地处理，不会上传图片数据
- 导出结果为 PNG 文件下载
