# 图片无损放大工具

一个纯前端的图片放大页面：拖拽或选择图片，调节放大倍数与平滑模式，直接在浏览器内生成放大结果并下载，无需上传到服务器。

## 使用方式

1. 本地运行（无需依赖）：

   ```bash
   npm start
   ```

   默认在 `http://localhost:3000` 提供在线页面。

2. 部署到线上：

   - 将本仓库上传到任意支持 Node.js 的托管平台（如 Vercel、Railway、Render），命令使用 `npm start` 即可作为静态站点运行。
   - 也可以直接将根目录的静态文件发布到支持静态站点的服务（如 GitHub Pages / Netlify）；若平台要求构建命令，可以指定空命令并将发布目录设置为仓库根目录。

3. 浏览器访问后上传图片，设置放大倍数，点击“开始放大”即可预览与下载结果。

## 功能
- 放大倍数 1.0x - 6.0x 可调
- 可选关闭平滑插值以获得像素风的清晰放大
- 本地处理，不会上传图片数据
- 导出结果为 PNG 文件下载
